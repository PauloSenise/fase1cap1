Projeto CardioIA - Fase 1: Batimentos de Dados
O CardioIA é um projeto focado no desenvolvimento de uma plataforma inteligente para o ecossistema cardiológico, integrando dados clínicos, Machine Learning e Processamento de Linguagem Natural (NLP).

Este repositório contém a base de dados inicial necessária para as futuras fases de treinamento e análise do projeto.

Parte 2 – Dados Textuais (NLP)

Foram selecionados dois textos técnicos (localizados na pasta /docs) que abordam desde métricas de sobrevida até definições de sintomas isquêmicos.

Como esses textos podem ser explorados por algoritmos de NLP:
Extração de Entidades Nomeadas (NER): O algoritmo pode identificar sintomas específicos (dor torácica típica, síncope, dispneia) e marcadores biológicos (troponinas) citados nos textos.

Classificação de Tópicos: Agrupamento automático de parágrafos que tratam de "Tratamentos" versus "Definições de Sintomas".

Análise de Sentimento e Gravidade: Interpretação da descrição subjetiva da dor relatada pelo paciente para priorização em triagens automáticas.

Justificativa e Relevância:
A análise de textos é vital para o CardioIA pois permite que a plataforma interprete dados não estruturados (como anotações médicas e artigos científicos), garantindo que o sistema de IA esteja sempre alinhado com as diretrizes da Sociedade Brasileira de Cardiologia e com as evidências de sobrevida pós-infarto.
